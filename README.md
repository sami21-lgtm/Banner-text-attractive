🌟 Banner Text Hover Effect Slider with Background Music
An elegant, fully animated image slider project. It features smooth background image zooming on slide changes, a unique scattered wave text animation for each letter, and a continuous background music experience that doesn't interrupt when slides change.

✨ Features
Smooth Image Zoom: The background image smoothly scales up (zoom-in effect) whenever a new slide becomes active.
Scattered Wave Text Animation: The individual letters of each slide's title (e.g., DESERT, OCEAN) slide and rotate into a wavy, dynamic alignment rather than appearing in a boring straight line.
Banner Glow Hover Effect: The main header text at the top features a smooth turquoise glowing effect when hovered over.
Continuous Background Music: Adhering to modern browser security policies, the background music seamlessly starts on the user's first click anywhere on the page and continues playing smoothly without resetting or pausing when switching slides.
Clean Code Structure: Fully modularized into separate HTML, CSS, and JavaScript files for easy customization.
